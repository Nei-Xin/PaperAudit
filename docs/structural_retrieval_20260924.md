# 2026-09-24 抽取隔离与结构证据召回

后续同预算对照已完成，默认审计策略调整为普通排序扩展，详见 [检索方案比较](retrieval_strategy_comparison_20260924.md)。以下保留本阶段结果。

本轮变更包括批次失败后的单来源抽取重试、补查证据编号必填校验，以及公式、表格与跨页文本的有限上下文扩展。

## 最终行为

- 抽取批次两次失败后，保留能够单独通过本地校验的来源，只重试缺失、重复或非法来源。单来源重试保留该句真正的前后相邻句。引用仍必须逐字匹配报告原文；重试耗尽仍返回明确失败，不静默返回不完整审计。
- 补查返回 `evidence_sufficient=true` 时必须包含至少一个 `evidence_id`；服务层继续验证 claim ID 和候选编号是否合法。
- PDF 解析仅增加启发式 `table/formula` 类型提示，原文、页码、chunk ID 和坐标保持原样。旧索引可在检索时推断类型，不需要重写索引。
- 审计保留原始 Top-K 候选及编号，再追加至多五个相关相邻块。结构块可携带同页上下文；跨页仅接受相邻页的同类结构块，或疑似未完句的续文。每个新增片段使用自己的原文、页码和编号，交由裁决器核验证据关系。
- 结构提示不代表已可靠重建表格行列或证明公式语义，不会放松证据充分性标准；复杂版面、页眉页脚干扰和图片公式仍有局限。

## 验证

252 个测试通过，包括非法引用隔离、重复来源重试、实际相邻句上下文、补查编号校验、旧索引公式召回、跨页表格和未完句、候选预算/去重/页距及服务层集成。

最初尝试的类型加权导致开发集 Top-5 召回降至 92.11%，已从最终实现中移除。改为追加候选后，十组现有离线回归全部达标，Top-5 指标与改动前一致；最终留出集保持 87.50%，仅用于回归验收，没有用于调参。

自然报告重放沿用冻结抽取与语义对齐，只比较完整抽取且参考已决的 317 条事实（184 个不同 claim）。按 chunk ID 和实际原文共同核对参考引文：

| 候选方案 | 引文全部命中 | 部分命中 | 未命中 | 每 claim 平均候选数 |
| --- | ---: | ---: | ---: | ---: |
| 原始 Top-5 | 246 | 7 | 64 | 5.00 |
| Top-5 + 至多5个结构相邻块 | 255 | 5 | 57 | 8.52 |
| 普通 Top-10 对照 | 277 | 11 | 29 | 10.00 |

结构扩展增加9条完整命中（77.60% → 80.44%），但普通 Top-10 的命中更多（87.38%）。因此不能声称结构扩展优于扩大候选范围；下一轮应比较普通扩展与结构上下文的组合，并同时衡量上下文成本和实际裁决表现。

本轮没有调用模型 API，没有重新测量端到端标签一致率或弃权率。失败审计、缺失/部分抽取和未决参考不在这个检索比较的分母内；同一 claim 可对应多个 fact，观测不独立。
