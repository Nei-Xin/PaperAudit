# PaperAudit 两分钟 Demo 录制脚本

目标时长：1 分 40 秒至 1 分 55 秒。录制应使用公开论文和演示用报告，不展示 `.env`、API Key、本机个人目录或未公开数据。

## 0:00–0:15 场景与输入

- 展示首页和论文项目列表。
- 旁白：PaperAudit 面向需要阅读和复核英文 AI 论文的学生、研究者与开发者，核心目标是让 AI 讲解能够回到论文原文核验。
- 上传一篇带文本层的公开 AI 论文 PDF，或打开已保存的演示项目。

## 0:15–0:45 论文讲解与证据定位

- 展示结构化中文讲解。
- 点击一个关键知识点的原文引用。
- 展示 PDF 自动跳转和高亮。
- 旁白：Hy3 负责语义理解，本地程序负责页码、原文和引用校验；模型不能自行提供未通过本地验证的页码。

## 0:45–1:15 报告审计主流程

- 打开“报告操作”，粘贴一段包含错误数字或遗漏实验条件的演示报告。
- 启动审计并展示论断拆分、支持标签、错误类型、风险等级和修改建议。
- 点击问题对应证据，回到 PDF 原文。
- 旁白：系统使用六维 Rubric，并区分支持、部分支持、矛盾、未找到支持和证据不足。

## 1:15–1:38 评测有效性

- 快速展示 `docs/direction_one_final_report.md` 的结果表。
- 旁白：最终独立留出集含 6 篇新论文、48 条论断；标签准确率 83.33%，Top-5 证据召回率 87.50%。40 条固定样本三次重复的一致率为 98.33%，并完成 10 组成对对抗验证。

## 1:38–1:52 边界与结束

- 展示一个“证据不足”或人工复核提示。
- 旁白：当前不支持扫描件 OCR、复杂表格可靠解析、图片理解或跨论文事实核验；模拟投稿建议不代表真实会议录用决定。
- 结束画面展示项目名称、公开仓库地址和“个人活动作品，非腾讯官方项目”。

## 录制后检查

- [ ] 总时长不超过 2 分钟。
- [ ] 至少完整展示一次“输入 → AI 结果 → 点击证据回到 PDF”的闭环。
- [ ] 至少展示一次报告审计问题和修改建议。
- [ ] 不出现 API Key、`.env` 内容、个人目录或浏览器私人标签页。
- [ ] 输出为仓库可访问的 MP4、WebM 或 GIF，并在 README 顶部增加链接或预览图。
