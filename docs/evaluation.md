# PaperAudit 评测 Rubric（方向一）

本文档定义 PaperAudit 对“中文论文讲解/审计报告”的可执行评测标准。评测对象是报告中的原子论断，证据来源限定为对应论文 PDF 的文本索引；不评价论文观点本身是否正确，也不复现实验。

## 1. 评测单位与标签

一条评测记录包含：论文、报告文本、原子论断、人工金标标签、错误类型、风险等级和原文证据。论断应能被单独判断，不能把多个互不依赖的事实写在同一条记录中。

### 1.1 支持标签

| 标签 | 判定标准 |
| --- | --- |
| `SUPPORTED` | 原文明确支持论断中的主体、关系、条件、数值/指标和结论强度；没有新增事实。 |
| `PARTIALLY_SUPPORTED` | 原文只支持论断的一部分，或论断遗漏了使结论成立的必要条件；未被支持的部分必须能指出。 |
| `CONTRADICTED` | 原文明确给出相反含义、冲突数值、不同数据集/任务或不同结果归属。 |
| `NO_SUPPORT_FOUND` | 在论文范围内找不到能支持论断的证据，且没有足够原文证明其为相反结论。 |
| `ABSTAIN` | 论文解析、候选证据或论断本身存在歧义，人工评审也无法可靠决定；不得把它当作错误。 |

### 1.2 错误类型

一条论断最多标记一个主要错误类型：

- `numeric_or_metric_mismatch`：数字、单位、指标名称或数值关系错误；
- `wrong_attribution`：把结果、贡献或方法归给错误主体；
- `missing_condition`：遗漏数据集、比较对象、实验条件等必要限定；
- `overgeneralization`：把局部实验结论扩大成无条件或全场景结论；
- `external_hallucination`：引入论文没有提供的外部事实；
- `contradiction`：与论文原文含义相反。

### 1.3 风险等级

风险表示该论断对读者形成错误理解的影响，而不是模型置信度：

| 等级 | 可操作标准 |
| --- | --- |
| `none` | 完全支持，且没有发现会误导读者的限定或引用问题。 |
| `low` | 非关键措辞不严谨，但不改变方法、结果或结论；修改后不影响主要理解。 |
| `medium` | 关键条件遗漏、轻微数字/指标错误、部分支持或局部过度概括，可能改变读者对适用范围的理解。 |
| `high` | 主要结果数字错误、结果归属错误、关键引用不匹配，或对核心贡献作明显过强表述。 |
| `critical` | 与原文相反的核心结论、伪造/不存在的关键证据，或会导致读者作出根本错误判断的论断。 |

评审者选择能够覆盖问题的最小等级；如果同时存在多个问题，优先记录对理解影响最大的一个。

## 2. 六维指标

所有维度输出 0–100 分；没有可计算样本时输出 `N/A`。

1. **事实支持度**：不含数字或指标的论断，`SUPPORTED=100`、`PARTIALLY_SUPPORTED=50`、`CONTRADICTED/NO_SUPPORT_FOUND=0`；`ABSTAIN` 不计入平均。
2. **证据正确性**：报告原本提供引用的论断中，引用无错误且标签为支持或部分支持的比例。
3. **证据完整性**：关键论断中提供原始论文证据引用的比例。
4. **数字与指标一致性**：含数字或指标的论断按第 1 条的标签分值平均；没有数字/指标的论断不进入该维度。
5. **内容覆盖度**：选定审计范围中，至少出现一条论断的类别比例；该指标只衡量覆盖，不代表该类别内容正确。
6. **结论边界**：贡献、方法、结果、局限类别中，未被标为 `missing_condition` 或 `overgeneralization` 的已判定论断比例。

总分是所有非 `N/A` 维度的等权平均，保留 1 位小数。总分不等于事实正确率。

## 3. 评测范围与样本构造

当前基准集选择 5 篇公开、可复核的英文 AI 论文，覆盖 NLP、视觉和参数高效微调。每篇论文构造 8 条论断：4 条支持/部分支持样本和 4 条错误、无支持或对抗样本；总计 40 条。错误样本包含数字变更、指标替换、条件删除、结果归属错误、过度概括、外部幻觉和伪造引用。

样本中的 `source_page` 和 `source_quote` 是人工金标定位。正式批量运行前，应将对应 PDF 下载到本地并重新生成 PaperAudit 的 `chunk_id`；不得仅凭页码判定支持关系。

## 4. 方向一有效性验证计划

- **判别力**：在同一论文上构造好、中、差三档报告；记录总分排序是否满足好 > 中 > 差，并统计排序正确率。
- **一致性**：相同模型、提示词和运行配置下重复评测 3–5 次，记录标签一致率、可信等级一致率、总分均值和标准差；在人工金标子集上计算标签准确率和宏平均 F1。
- **对抗性**：增加篇幅、堆砌术语、伪造页码/引用但不改变事实支持关系，检查分数是否不会被表面形式性提升。

## 5. 标注流程

两名评审者独立标注标签、错误类型、风险等级和证据；分歧由第三次复核或共同讨论解决，并保留原始分歧。测试集标注完成后不得再根据模型结果修改金标。
