# PaperAudit 方向一首轮基线

运行命令：

```powershell
uv run python eval/prepare_evidence.py
uv run python eval/run_eval.py --top-k 5
```

评测使用 `resolved_samples.jsonl` 中的 40 条固定原子论断，不重新调用论断拆分；这样本轮结果只衡量“论文证据检索 + 支持关系判断”。模型配置和候选数量记录在 `results/metrics.json`。

## 结果解释

标签层面已经能区分大多数支持、冲突和部分支持样本，但宏平均 F1 低于准确率，说明少数类别和边界样本仍不稳定。错误类型识别高于标签识别，表示模型通常能识别“哪里有问题”，但在“问题属于完全冲突还是部分支持”上更容易摇摆。

检索是当前最明显的瓶颈：默认 Top-5 只覆盖 38 条金标证据中的约一半；同一脚本的干跑 Top-12 召回率约为 65.79%。这说明摘要长、术语重复或数字不突出的证据块容易被 BM25 排在候选集之外。该结果不能直接当作 Hy3 判断能力的下限，应在后续实验中分别报告检索命中和判断准确率。

本轮还不是方向一最终有效性结论：样本金标尚未完成第二位评审者独立复核，也尚未进行好/中/差排序实验和重复运行一致性实验。下一步应冻结当前样本与 Rubric，补充人工复核记录后再做这些验证。
