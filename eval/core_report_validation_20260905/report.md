## 核实后的核心问题

### 1. 原文引用被拆散并丢失，应优先修复

报告的典型格式为 `事实。（证据：论文第2页）`。当前分句把句号后的引用变成另一个来源单元，模型通常将其作为 `non_claim` 跳过，事实的 `provided_evidence` 变为 null。

本轮 28 个原本带引用的事实来源 × 3 次 = 84 次观察，仅 3 次保留了引用，全部来自 R005 的第二次运行。R018 中明确伪造的“第999页，表99”三次均未被标为 `fabricated_evidence`，尽管相邻事实本身被判为高风险。

引用丢失也影响评分：R005 第一次、第三次的引用完整性为 0，第二次为 33.3；引用正确性从不适用变为 100。这说明三次分数 78 / 87 / 78 的差异受到引用提取波动影响，不能理解为报告质量真的变化。

**最小修复方向：**本地保留事实与句末引用的关联，按来源将原有引用补回论断；不再依赖模型跨来源重新猜测绑定。补一个“正常页码保留”和一个“第999页检出”的完整链路测试。

### 2. “范围外”跳过了应审计的实验事实

以下两条三次都没有抽取，均在结果中被记录为 `out_of_scope`：

- R002 / S0021：“论文在基准数据和商业数据上评估 DeepFM。”
- R018 / S0015：“实验在 MNIST 和 CIFAR-10 图像分类任务上评估方法。”

既有标注将它们归为 `results`，本轮请求范围包含 `results`，但不包含 `dataset_setup`。因此事实与实验设置的分类边界是一个明确排查方向；当前输出只保留跳过原因，没有保留模型给被跳过句子分配的类别，不能断言具体内部归类。

R018 三次非弃权比例均为 100%，但每次都漏掉一个事实。逐句返回校验只能证明每句有答复，不能验证模型的跳过理由正确。

**最小修复方向：**明确实验设置与实验结果在本次审计范围中的边界，携带原报告章节信息；对事实性句子的 `out_of_scope` 决定进行一次范围核对，而不是把它直接当成抽取完成。

### 3. 候选未召回，被放大为正确内容高风险误报

R005 / S0016：“DIP 通过在单个退化图像上拟合生成器网络来恢复图像。”三次均被判 `NO_SUPPORT_FOUND / external_hallucination / high`。

已核对论文第 2 页 `p2_b3` 原文，明确包含：

> we fit a generator network to a single degraded image

前两次 Top-5 候选为 `p1_b10`、`p1_b9`、`p1_b30`、`p1_b12`、`p1_b32`；第三次为 `p1_b9`、`p1_b10`、`p1_b30`、`p1_b12`、`p1_b31`。三次均缺少支持它的 `p2_b3`。因此这是可核实的召回失败与后续误判，不是报告杜撰。仅凭当前候选中没有该方法描述，就给出高风险外部臆测，会误伤正确报告。

**最小修复方向：**恢复引用后利用原报告页码补取对应原文；对于高风险“无支持”判断，做一次针对核心短语的补充检索。证据仍不足时保留人工复核，避免只凭未召回就断言事实虚构。用此正例和现有虚构数字、虚构部署负例同时验证。

## 其他解释边界

R018 的“完全没有成本”和“绝不会泄露任何信息”由旧金标的中风险变为高风险，属于规则口径差异；前者原文明确提到适度成本，后者涉及绝对保证，不能仅因与旧金标不同就认定为误报。本轮没有反向修改旧标注。上述 4.55% 高风险误报只统计金标受支持内容，并已核对真实原文。

本轮每篇论文只选了一档，不能检验同一论文的高、中、低档排序，也不能把整体得分降低解释为评分校准改善。当前优先修复引用绑定、范围漏抽、候选不足后的误判；不建议根据这轮分数继续调整评分权重。
