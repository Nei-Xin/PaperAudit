# 引文修复边界修正

推送前检查发现两个未被此前真实 API 回归覆盖的问题：纠正建议未验证时仍可能进入
引文格式修复；修复请求未携带原始建议，模型可能遗漏复核记录里没有提及的比较数值。

本次修正：

- 有纠正建议时，只有 `suggestion_verified=true` 且 `suggestion_missing_aspects` 为空，
  才允许对本地校验失败的引文进行一次格式修复。语义缺口不会通过格式重试重新评判。
- 修复接口必须接收原始判断，把完整建议和解释放入不可信数据区；提示明确要求覆盖
  附加比较，不得缩短建议来隐藏缺口。
- 修复结果仍使用原始判断执行完整门禁。失败时保留 ABSTAIN、清除建议，不再次重试。
  旧支持复核缺少新字段时的既有加载和直接校验行为保持兼容。

先新增测试复现问题：6个语义缺口案例错误触发修复，3个请求测试发现原始判断缺失。
修复后扩大到支持/矛盾两种目标、缺字段/明确失败/矛盾字段、同时存在错误引文的情况，
以及修复返回建议验证失败的情况。新增16个参数化案例，全量 **357项测试通过**。
请求测试使用真实客户端的提示构造与结构解析，替换网络返回，验证发送的 JSON 中
包含完整原始建议。此次未新增真实 API 调用，之前18/18结果属于修复前的冻结版本。
